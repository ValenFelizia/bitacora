# Letras para elegir sin conexión

Seis familias de Google Fonts, con licencia SIL OFL 1.1 incluida en cada
carpeta. `procedencia.json` registra URLs oficiales, revisión del repositorio,
tamaños y SHA-256. `scripts/issue7-fonts.mjs` en el repositorio de Bitácora
permite repetir la descarga; la agencia no necesita internet ni ejecutar nada.

- Lora: títulos serif de lectura tranquila.
- Fraunces: serif expresiva para títulos cortos.
- Manrope: sans de lectura clara en celular.
- Source Sans 3: alternativa sobria para detalles largos.
- Outfit: display geométrica para títulos y bloques modernos.
- Caveat: manuscrita para acentos cortos, nunca para condiciones o precios.

Se incluyen pesos 400 y 600 y el subconjunto latino, con áéíóúüñ y mayúsculas.
Las plantillas enlazan `fuentes.css` por ruta relativa dentro de la agencia.
No borres ni separes los archivos OFL al compartir las fuentes.
